# 📅 Календарь заметок

Личный и общий календарь для заметок с уведомлениями.

## ✨ Функционал

- 🔐 Регистрация и вход с подтверждением email
- 👤 Личный календарь (только для вас)
- 🌍 Общий календарь (видят все пользователи)
- 📝 Создание, просмотр и удаление заметок
- 🔔 Уведомления о заметках на текущую дату

## 🚀 Демо

[Ссылка на GitHub Pages](https://zefir.github.io/calendar-app/)

## 🛠 Технологии

- HTML5, CSS3, JavaScript
- Firebase Authentication
- Firebase Realtime Database
- GitHub Pages

## 📦 Установка

1. Клонируйте репозиторий
2. Откройте `config.js` и вставьте свои Firebase ключи
3. Загрузите на GitHub и включите GitHub Pages

## 📝 Настройка Firebase

1. Создайте проект в [Firebase Console](https://console.firebase.google.com/)
2. Включите Authentication (Email/Password)
3. Создайте Realtime Database
4. Скопируйте конфигурацию в `config.js`
5. Добавьте домен `zefir.github.io` в Authorized domains
